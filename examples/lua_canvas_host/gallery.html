常用 API 参考

Lua 侧画布能力一共有 5 个绘制方法 + 3 个输出方法。 所有方法都只往显示列表里追加数据，不会立即触发任何绘制。

创建

方法 参数说明
canvas.new(opts) width, height, background 创建画布。缺省800×600，深色背景 #0f1116。尺寸是逻辑值，宿主按DPR 缩放。

绘制 — 五种图元

方法 参数说明
c:circle(x, y, r, style) 圆心 x,y 半径 r
style: fill, stroke, stroke_width		 圆形。可只填色、只描边或两者都有。
c:rect(x, y, w, h, style) 左上角 x,y 宽高 w,h
style: radius, fill, stroke, stroke_width		 矩形。radius 给圆角，0 为直角。
c:line(x1, y1, x2, y2, style) 起点 x1,y1 终点 x2,y2
style: stroke（默认白）, stroke_width（默认 1）		 直线。坐标轴、网格线、引线都用它。
c:polygon(points, style) {x=,y=} 数组，至少 3 个
style: fill, stroke, stroke_width		 多边形。折线也走这个（不闭合时按折线处理）。
c:text(x, y, str, style) 基线起点 x,y
style: size(14), color(白), align(left)		 文本。align 可选 left / center / right，y 是基线不是顶边。

输出

方法 返回说明
c:build() 显示列表 table 交给宿主消费的最终产物。 结构：{version, width, height, background, ops[], op_count, fingerprint}。
c:hash() 8 位十六进制字符串 内容指纹。宿主用它判断是否需要重绘—— 指纹相同就跳过整帧。数据变了才会变。
c:clear() 画布自身 清空图元但保留尺寸和背景，可链式调用。

能力契约层

方法 参数说明
require_cap(name, opts) opts: min_version, reason 业务侧声明必需能力。缺了立刻报错并带上声明理由；版本不达标也报错。
cap(name) — 可选能力，缺失返回 nil，用于降级分支。
provide(name, impl, opts) opts: version, desc 宿主侧注册能力。重复注册会报错，便于发现拼写错误。
verify() — 启动时统一校验所有声明过的依赖，返回缺失清单。避免运行到一半才崩。

样式字段速查

字段 取值说明
fill / stroke #rgb / #rrggbb / #aarrggbb 颜色。#aarrggbb 的 alpha 用于渐隐效果。 非十六进制会在 Lua 侧直接报错。
stroke_width 数字，0 表示不描边 描边宽度。0.5 常用于网格线做抗锯齿。
radius 数字，0 为直角 圆角半径，矩形专用。
size 数字（逻辑像素） 字号。宿主按设备像素比缩放。
align "left" / "center" / "right" 文本对齐。右对齐时 x 表示文本右边缘。

常用绘制辅助模式

模式 做法说明
canvas.OP circle / rect / line / text / polygon 图元类型常量表。做分发逻辑时用，别硬编码字符串。
动画循环 tick(data) 只改数据
draw(data) 只读数据		 严格分离。tick 不碰画布，draw 不改数据。 每帧跑 tick + draw，指纹变了宿主才重绘。
图表坐标映射 to_x(i, n) / to_y(v) 纯函数 数值到像素的映射写成纯函数，不含绘制逻辑， 因此可以脱离渲染单独测试。
状态配色 status_color(status) 业务规则映射到视觉表现。规则在 Lua，宿主只管照着画。
